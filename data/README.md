# Данные — Игорь

Формат реальных данных организаторов описан в аудите Георгия; сами данные
не добавляются в репозиторий и отсутствуют в этой рабочей папке.
Аудит здесь не повторялся. Агрегированные результаты находятся в
[ml/reports/data-audit.md](../ml/reports/data-audit.md).
Нельзя автоматически публиковать материалы организаторов: сначала изучите правила и разрешения.
Исходные и обработанные данные храните внутри этой директории локально; Git по умолчанию игнорирует всё, кроме этого README и явно разрешённой директории `synthetic/` для будущих проверенных примеров.
Текущий синтетический пример `ml/forecast.py` по-прежнему проверяет HTTP-связку и
не подменяет реальную модель. Потоковая сборка target, temporal backtest, batch
inference и submission-адаптер реализованы в `ml/`; команды описаны в
[ml/README.md](../ml/README.md). Для готового CSV реализован отдельный
[handoff-контракт](../backend/handoff/README.md); общий v2, привязка справочников
к карте и полная приёмка UI/API/CSV остаются на согласовании.
Контракты и изменения фиксируются в [INTEGRATION.md](../INTEGRATION.md).
