# Данные — Игорь

Реальные данные появятся после старта; формат пока неизвестен.
Нельзя автоматически публиковать материалы организаторов: сначала изучите правила и разрешения.
Исходные и обработанные данные храните внутри этой директории локально; Git по умолчанию игнорирует всё, кроме этого README и явно разрешённой директории `synthetic/` для будущих проверенных примеров.
Текущий синтетический пример находится в `ml/forecast.py`. Он проверяет взаимодействие компонентов и не подтверждает качество модели.
Парсер, протокол эмулятора и формат отправки намеренно не реализованы.
Контракты и изменения фиксируются в [INTEGRATION.md](../INTEGRATION.md).
