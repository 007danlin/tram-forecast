# Frontend — Артём

Одна страница React: шапка с навигацией (Карта/Аналитика/Настройки), верхняя панель фильтров,
карта, плавающая карточка прогноза слева снизу и нижняя временная панель. Загрузка, ошибка,
повтор запроса, SVG-график и таблица встроены в карточку и в раздел «Аналитика».
Настройка прокси и команды: [INTEGRATION.md](../INTEGRATION.md).
Зависимости зафиксированы в `package-lock.json`; устанавливайте через `npm ci`.

## Оболочка интерфейса и ML handoff

Интерфейс взят целиком из переданного Артёмом commit `91eb466`: AppHeader,
FilterBar, Workspace, ForecastCard, ForecastData, TimelinePanel, AnalyticsView,
SettingsPanel и их оформление. Карта заполняет экран, фильтры и карточка плавают
поверх неё; вкладки Карта/Аналитика/Настройки и таймлайн сохранены.
По поручению Даниэля изменено подключение данных: прежний synthetic v1 заменён
проверенным `/api/v2/handoff/*`, без изменения HTTP-контракта.

`useForecast.ts` управляет ready → capabilities → query и закреплённым export;
`handoff.ts` валидирует ответы и границы МСК. Компоненты используют один результат.
Маршруты/даты берутся из пакета, первый день исторический. Кнопки «1 день»,
«1 нед», «1 мес» дают часовой или дневной ряд; период вне диапазона блокируется.
Остановки, направления, год и сценарии отключены с пояснением, данных для них нет.
Карта сохраняет pan/zoom/выделение при обновлении и смене вкладок; связи её линий
с прогнозным селектором нет. «По участкам» не содержит выдуманного прогноза.

График оставляет разрывы для null, таблица раскрывает raw float и покрытие,
итог приходит из API. № 5 обозначен нулевым baseline, а не отсутствием движения.
В подробностях доступны run, model, CSV checksum и ограничения. CSV содержит
тот же результат без округления; он отличается от конкурсного submission.
Ошибки 503/410/409, смена фильтров и загрузка блокируют экспорт. Старые запросы
отменяются; без ML-пакета синтетический прогноз не подставляется.

Сохранены lock с Playwright и проверка полноты карты перед сборкой. Иконка
`frontend/public/tram-icon.png` из commit Артёма включена в Git и web ZIP.
Дополнительные CSS-правила ограничивают перенос длинных run/checksum/чисел;
компоновка и стили компонентов остаются авторскими.

### Проверка

```sh
npm ci --prefix frontend
(cd frontend && npx playwright install chromium)
NODE_PATH="$PWD/frontend/node_modules" QA_BROWSER=chromium python tests/frontend/run_browser.py
# Отдельно с импортированным реальным пакетом:
QA_RELEASE="$PWD/artifacts/releases/my-release" \
  NODE_PATH="$PWD/frontend/node_modules" QA_BROWSER=chromium python tests/frontend/run_browser.py
```

Python требует backend/requirements.txt. Проверка запускает изолированные сервисы
на свободных localhost-портах, проверяет отсутствие пакета/восстановление,
batch/API/UI/CSV, периоды, ошибки, null/partial, отмену старых результатов,
МСК в немосковском браузере, клавиатуру, карту/навигацию и 1366/390 px.
Скриншоты: `artifacts/verification/ui-{synthetic,real}/`. Синтетический CI
не подтверждает качество модели. Установка release описана в
[handoff README](../backend/handoff/README.md).

## Карта трамваев

Линии маршрутов рисует само приложение (SVG из осевых линий, извлечённых из PDF); ни растра, ни копии PDF в браузере нет; pan/zoom — колесо, перетаскивание, pinch, кнопки, клавиатура.
Схема заполняет контейнер целиком (`object-fit: cover`-подобное поведение — `fit = Math.max(w/pageW, h/pageH)` в `TramMap.tsx`, вместо `Math.min` "contain"), без пустых полей на любом соотношении сторон; при `MIN_ZOOM` обрезаются края, а не остаются пустыми. Стартовый вид — центр на «Чистые пруды» с приближением (`DEFAULT_CENTER`/`DEFAULT_ZOOM` в начале `TramMap.tsx`), а не вся схема целиком мелко; кнопка/клавиша «0» возвращает к этому виду (её подпись и `aria-label` обновлены — раньше она буквально показывала всю схему, сейчас это уже невозможно без пустых полей).

Под схемой — просто заливка страницы (`--map-land` в `style.css`), без декоративного фона. По ходу задачи пробовали: реальные тайлы OpenStreetMap через Leaflet (визуальный шум, конфликт с подписями схемы) и рисованную векторную подложку «город» — сначала без учёта данных схемы (кварталы/река пересекали линии), затем с occupancy-сеткой по реальным координатам линий/подписей/остановок из `network.json`, чтобы ничего не пересекалось. По результату решили, что декоративный фон в любом виде не нужен — оставили только заливку. Тема одна (светлая).
Готовый `frontend/public/map-local/network.json` сохранён из main и поставляется в Git.
PDF и OCR для запуска не нужны; исходный PDF в `data/tram-map/` остаётся локальным.
Следующие команды предназначены только автору карты:

```sh
pip install -r scripts/map/requirements.txt
python scripts/map/extract_lanes.py             # читает data/tram-map/trammap_15_04_26-2.pdf
```

Без готового полного network.json сборка останавливается. Выбор линии работает
по ближайшей геометрии; остановочный прогноз не реализован. Геометрия, цвета и
данные схемы этой интеграцией не менялись.

Номера маршрутов на линиях и цветовая легенда получаются вторым шагом (после `extract_lanes.py`):

```sh
python scripts/map/label_lanes.py   # распознаёт номера на линиях по эталонам из легенды PDF, дописывает routes/legend в network.json
```

Линии без надписи на схеме получают номер по соседям или по ручному списку `OVERRIDES` в скрипте; такие линии помечены `inferred` и требуют проверки.

Остановки и подписи (все линии):

```sh
pip install winocr                   # только Windows 10/11 с языком OCR «ru»
python scripts/map/build_stops.py    # точки остановок и подписи из PDF, тексты — OCR
```

Точки — круги на осевых линиях; подписи — тёмные контуры текста из PDF, повёрнутые под тот же угол; тексты распознаются OCR (текст в PDF переведён в кривые).
Исправления OCR — в локальном `data/tram-map/stop-overrides.json` (`{"text": {"как распознано": "как правильно"}, "at": [[x, y, "текст"]]}`). Отчёт со спорными местами: `data/tram-map/stops-report.json`. Подпись привязана к точкам по геометрии; остановки не объединяются между линиями автоматически.

Достопримечательности и значки метро/МЦК:

```sh
python scripts/map/build_icons.py    # контуры иллюстраций и значков «М» из PDF -> network.json (landmarks, metro)
```

Иллюстрации (МГУ, Кремль и др., с подписями) и значки станций рисуются как векторные контуры из PDF, сгруппированные в объекты; включены в готовый network.json.
