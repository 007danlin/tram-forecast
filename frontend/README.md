# Frontend — Артём

Одна страница React с загрузкой, ошибкой, повтором запроса, SVG-графиком и таблицей.
Настройка прокси и команды: [INTEGRATION.md](../INTEGRATION.md).
Зависимости зафиксированы в `package-lock.json`; устанавливайте через `npm ci`.

Экран использует работающий `/api/v2/handoff`: ready → capabilities → query.
Маршруты, даты и шаги получаются из пакета; первый выбранный день исторический,
а не текущая дата компьютера. День содержит 24 часа, неделя 7 суток,
месяц — все календарные дни. Выходящие за доступные границы периоды блокируются
с объяснением. МСК задаётся явно и не зависит от зоны браузера.

График, таблица, общая сумма и покрытие берутся из API. Значения показываются
до двух знаков, исходная точность доступна в таблице и не теряется при экспорте.
CSV закреплён на последнем показанном result_id и filters; загрузка, ошибка
или изменение фильтров блокируют экспорт. 503, 410, 409, partial и no_data
показаны отдельно; автоматической подмены синтетикой нет. № 5 обозначен baseline.
Run, ограничения и режим данных видны в раскрываемых подробностях.

Из переданного пользователем commit Артёма `91eb466` интегрированы изменения `TramMap`:
начальный вид у Чистых прудов, заполнение контейнера, выбор ближайшей линии по геометрии
и отображение выделенной линии поверх соседних. Кнопка/клавиша 0 возвращает исходный вид.
Готовый network.json и предупреждения поставки сохранены из main. Synthetic v1-оболочка
того commit не переносилась: текущие handoff-фильтры/CSV сохранены.
Карта остаётся независимым компонентом и не перемонтируется при запросах.
Нет выдуманной связи номеров API с линиями схемы; остановки, направления,
сценарии и численный год не предлагаются. При отсутствии установленного
пакета экран показывает его недоступность. Установка — в
[памятке handoff](../backend/handoff/README.md).

Браузерная проверка запускает временный backend и Vite на свободных localhost-портах,
синтетический полный batch, проверяет отсутствие release и восстановление,
сверяет UI/CSV с исходными числами, проверяет ошибки,
быстрые изменения, клавиатуру и ширины 1366/390 px. Playwright зафиксирован в lock.

```sh
npm ci --prefix frontend
(cd frontend && npx playwright install chromium)
NODE_PATH="$PWD/frontend/node_modules" python tests/frontend/run_browser.py
# Для отдельного smoke настоящего импортированного пакета:
QA_RELEASE="$PWD/artifacts/releases/my-release" \
  NODE_PATH="$PWD/frontend/node_modules" python tests/frontend/run_browser.py
```

Нужен Python с `backend/requirements.txt`; ML-зависимости браузерному тесту
не требуются. `QA_BROWSER=chrome` позволяет использовать установленный Chrome.
Скриншоты сохраняются локально в `artifacts/verification/ui-{synthetic,real}/`.
Workflow `handoff-browser.yml` проверяет синтетический пакет без внешних данных.

## Карта трамваев

Линии маршрутов рисует само приложение (SVG из осевых линий, извлечённых из PDF); ни растра, ни копии PDF в браузере нет; pan/zoom — колесо, перетаскивание, pinch, кнопки, клавиатура.
Готовая карта `frontend/public/map-local/network.json` должна храниться в Git вместе с интерфейсом. Все участники получают её обычным `git pull --ff-only`; Python, PDF и OCR для запуска и сборки не нужны. Исходный PDF и промежуточные файлы в `data/tram-map/` остаются локальными.

Подпись в интерфейсе перечисляет линии, остановки и подписи и сообщает, что схема
пока не связана с прогнозом. Если готовая карта отсутствует, пользователь видит
предложение обновить страницу и обратиться к администратору; инструкции подготовки
PDF/OCR предназначены только автору карты и не выводятся на экран диспетчера.

Следующие шаги нужны только автору для изменения карты:

```sh
pip install -r scripts/map/requirements.txt
python scripts/map/extract_lanes.py             # читает data/tram-map/trammap_15_04_26-2.pdf
```

Перед сборкой `npm run build` автоматически проверяет наличие полной карты: линии, остановки, подписи, легенду, достопримечательности и метро. Без них сборка завершается ошибкой, в том числе в CI и Docker. Проверка комплектации не подтверждает точность OCR или геометрии.

Номера маршрутов на линиях и цветовая легенда получаются вторым шагом (после `extract_lanes.py`):

```sh
python scripts/map/label_lanes.py   # распознаёт номера на линиях по эталонам из легенды PDF, дописывает routes/legend в network.json
```

Линии без надписи на схеме получают номер по соседям или по ручному списку `OVERRIDES` в скрипте; такие линии помечены `inferred` и требуют проверки.

Остановки и подписи (все линии):

```sh
pip install winocr                   # только Windows 10/11 с языком OCR «ru»
python scripts/map/build_stops.py    # точки остановок и подписи из PDF, тексты — OCR
```

Точки — круги на осевых линиях; подписи — тёмные контуры текста из PDF, повёрнутые под тот же угол; тексты распознаются OCR (текст в PDF переведён в кривые).
Исправления OCR — в локальном `data/tram-map/stop-overrides.json` (`{"text": {"как распознано": "как правильно"}, "at": [[x, y, "текст"]]}`). Отчёт со спорными местами: `data/tram-map/stops-report.json`. Подпись привязана к точкам по геометрии; остановки не объединяются между линиями автоматически.

Достопримечательности и значки метро/МЦК:

```sh
python scripts/map/build_icons.py    # контуры иллюстраций и значков «М» из PDF -> network.json (landmarks, metro)
```

Иллюстрации (МГУ, Кремль и др., с подписями) и значки станций рисуются как векторные контуры из PDF, сгруппированные в объекты; входят в итоговый `network.json`, который автор добавляет в Git.

## Передача обновления всей команде

После всех шагов подготовки автор проверяет карту (`npm run check:map --prefix frontend`), визуально сверяет её и включает **готовый network.json** в тот же commit/PR, что и код. Повторный запуск `extract_lanes.py` перезаписывает карту: после него нужно повторить остальные шаги. PDF, OCR-кэш, датасеты и секреты в commit не включаются.

После слияния в main участники на чистой ветке main выполняют `git pull --ff-only origin main`. Эта команда получает код и карту; для обновления зависимостей используется `npm ci --prefix frontend`. Запущенный dev-сервер при необходимости перезапускается.

Готовый network.json получен от Артёма через пользователя и включён в рабочую папку: 45 линий, 1098 точек остановок, 424 подписи, 47 достопримечательностей и 58 значков метро. Эти числа описывают элементы схемы, а не уникальные транспортные объекты. Файл и настройки поставляются вместе; автор обновляет их одним PR в main.
