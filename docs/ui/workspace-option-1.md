# Вариант 1: компактное рабочее место

Дата: 26.09.2026. Статус: опубликовано на tramflow.ru с уточнениями пользователя.
Основа: выбранный пользователем [макет Figma](https://www.figma.com/design/lAPcp9do9tKBBt3BcVR1hz?node-id=24-163).
Общий стиль — «Вечерняя смена» с красным RGB(228,0,13) из
[брендбука Московского транспорта](https://transport.mos.ru/brandbook).
Шрифт — существующий локальный Manrope; официальный Moscow Sans не добавлялся.

## Поведение

- Основной экран компьютера: общие фильтры, карточка 320 px, интерактивная карта,
  временная панель. Сумма и пик видны рядом с выбранным интервалом.
- Аналитика: три показателя, график и таблица в соседних панелях; локальный скролл таблицы.
- Телефон: карта со сводкой на одном экране, подробный прогноз по «График»
  или свайпу вверх. Постоянная нижняя навигация карта/прогноз. Меню «…»
  рядом с датой, «Данные» в шапке. При первом открытии видна вся сеть.
  Сравнение открывается из списка «Маршрут» → «Сравнить маршруты».
  В обзоре скрыты дополнительные столбцы, но сохранены пометки отсутствия истории
  и неполных данных. Выбор маршрута открывает его прогноз.
- Ручные поправки: черновик процентов, четыре фактора, сброс черновика,
  явное применение. Закрытие окна отменяет неприменённые изменения.
  Проценты переводятся в прежние коэффициенты; backend и умножение не менялись.
- Год: отдельное окно «На год: допущения», три кратких условия и раскрываемые
  исходные пояснения. Численного года нет; окно сохраняет текущий расчёт.
- Данные: вкладки Прогноз/Источники/Паспорт. Источники открывают описание,
  свежесть, записи и атрибуцию по нажатию; данные берутся из monitoring API.
- Точные числа, MSK, null-разрывы, coverage, baseline и закреплённый CSV сохранены.
  У полной таблицы скрыт избыточный столбец покрытия, при пропусках он появляется.
- Native dialog обеспечивает клавиатурный фокус, Escape и возврат к вызвавшей кнопке.
  Существующая карта сохраняет компонент, камеру и обработчики pan/zoom.

## Локальная проверка

Источником служил существующий пакет `calendar-interaction-ensemble-b2`:
`handoff-dd668e2870ae1b4069c689811d15ae6c5f6ff7668e4db04c64a452d4e30d03ed`.
Реальные данные в Git не добавлялись. API: 127.0.0.1:8191, Vite: 127.0.0.1:5191.
Мониторинг в проверочном процессе выключен через `TRAMFLOW_MONITOR_ENABLED=0`;
окно честно показывает отсутствие снимков. Это не проверка живых коллекторов.

Пройдены:

- `npm --prefix frontend run build`: TypeScript, Vite, комплектность карты,
  35 групп / 36 номеров / 45 линий, выбор остановок/надписей/символов и плавные контуры.
- `python -m backend.handoff.check --base-url http://127.0.0.1:5191
  --release artifacts/releases/calendar-interaction-ensemble-b2`: все 10 маршрутов,
  первая и последняя даты пакета, исходный CSV = часовой API = дневные суммы = экспорт.
- Через встроенный браузер: компьютер 1440×900, 1366×768, 1024×768; телефоны
  390×844, 360×800, 320×844. Обычный основной экран не имеет внешней горизонтальной
  прокрутки; на проверенных размерах ноутбука карточка и действия помещаются.
- Аналитика: график и таблица одновременно, прокрутка внутри таблицы; SVG не
  перекрывает заголовок/временную панель на 1024×768. На телефоне отдельные виды.
- Ручной сценарий маршрута 1: база 18852.50967383226, погода +10%, перекрытия −10%,
  итог 18663.98457709394 = база ×1.1×0.9. Отображаются база и разница.
- Годовые допущения, вкладки данных, паспорт run, Escape и возврат фокуса.
- Семь дней маршрута 1: сумма строк таблицы и KPI = 108967.44608734592.
- №5 показывает нулевую модель и предупреждение; №2 «только схема» очищает KPI
  и блокирует экспорт. Навигация карта/аналитика/карта сохраняет viewBox.
- Нижняя навигация телефона, обзор, светлая тема, увеличение карты и Escape.
- Кнопка CSV вызвала успешный HTTP 200 export; CSV отдельно проверен handoff-check.
  Встроенный браузер не вернул событие download, поэтому сохранение файла через
  его менеджер загрузок в этом проходе не подтверждено.
- Консоль просмотренной страницы без JS ошибок/предупреждений.
- `node --check` для браузерных сценариев и `git diff --check`.

Обновлены существующие браузерные сценарии handoff, compact-card, scenarios,
route-focus, map-polish, dispatcher, monitoring, webkit-smoke. Добавлен общий helper
для новой навигации. Численные, CSV, race, null/coverage и картографические проверки
сохранены; проверки сворачивания старой карточки заменены проверками мобильных
представлений. Полный Playwright `run_browser.py` и отдельный WebKit в этом проходе
не запускались. Их результаты не считаются пройденными на основании синтаксиса.
