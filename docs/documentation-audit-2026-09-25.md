handoff API/install/store/check, общим draft, frontend и Vite-прокси,
ML CLI/artifact/data/evaluation/factors, Dockerfile и тремя Compose-файлами,
updater/Caddy, инструментами доступа/сдачи, правилами Git/Docker exclusions,
CI и существующими тестами. Изучены изменения ML из PR № 2/3, backend handoff
из `434bbca` и локальные QA-дополнения, вошедшие в `2c67772`.

В ходе проверки в общем рабочем дереве **параллельно продолжилась другая работа**:
появились изменения реального UI, updater, упаковщика ML и новые тесты.
Они не создавались этим аудитом и не откатывались. Состояние опубликованного
коммита отделено от этих незавершённых изменений; нельзя выдавать проверки базы
за приёмку нового UI/updater. Перед публикацией нужно повторно сверить документацию
с окончательным diff этой работы.

Проверка GitHub/main и VPS в другой работе описана отдельно в
[аудите комплектности](reproducibility-audit-2026-09-25.md). Его результаты имеют

## Выполненные проверки базы

Окружение: macOS arm64; backend/tooling — существующая `.venv`, Python 3.14.7;
ML — существующее отдельное окружение Python 3.12.14; Node 22.22.2.
В основной `.venv` ML-зависимостей нет; поэтому единая команда всех тестов
требует установки обоих requirements, как теперь указано в README.

Всего **77 тестов**. Первоначально HTTP-тесты не могли привязать localhost-порт
из-за песочницы; повтор с разрешённым локальным запуском прошёл. Caddy использовал
временные credentials/CA и localhost, без изменения публичного сервера.
DeprecationWarning FastAPI/Uvicorn на Python 3.14 и предупреждение joblib о числе
физических ядер не стали падениями тестов; базовый Python проекта/CI — 3.12.

Не выполнялись: новое обучение, независимый аудит raw/sample или качества модели,
повтор импорта реального пакета, Docker build/up, нагрузочные измерения,
браузерная приёмка нового экрана, проверка удалённого CI и публикация.
