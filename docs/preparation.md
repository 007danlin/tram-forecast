# Что подготовлено до хакатона

Дата: 2026-09-19. Заготовка создана с помощью Codex по ТЗ команды; этот перечень можно использовать для раскрытия предварительной подготовки при сдаче.

- Monorepo, распределение ответственности, правила веток/PR и общий документ интеграции.
- React + TypeScript + Vite: одна страница, API-запросы, статус, график, таблица, загрузка и ошибка.
- FastAPI: доступность сервиса и выдача временного тестового ряда, проверка ответа ML.
- Python-функция с шестью фиксированными синтетическими точками; это не обученная модель.
- Локальные команды запуска, Dockerfiles и Compose, примеры окружения, фиксация зависимостей.
- Небольшие интеграционные проверки и правила хранения данных.

Не подготовлены: парсер материалов организаторов, протокол эмулятора, формат отправки на платформу, признаки, модель, обучение, оценка качества, карта, фильтры, география, интервалы неопределённости и несколько горизонтов.
Ничего не опубликовано; сервер и домен не приобретались. Существующая лицензия сохранена.
Результаты фактических проверок приведены в [verification.md](verification.md).
