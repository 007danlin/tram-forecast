Браузерный прогон использует `httpCredentials` в свежем контексте, а не ввод
пароля человеком в системное окно. `ignoreHTTPSErrors` применяется только к
изолированному localhost с временным CA; отдельные Python HTTPS-тесты проверяют
цепочку этого CA. Это не разрешает игнорировать ошибки публичного сертификата.

Повторить browser QA после сборки frontend, при доступных Chrome и Playwright:

```sh
CADDY_BIN=/absolute/path/to/caddy \
QA_NODE=/absolute/path/to/node \
NODE_PATH=/absolute/path/to/node_modules \
.venv/bin/python tests/access/run_browser_check.py
```

`QA_SCREENSHOT=/absolute/path/browser.png` необязателен. Все серверы тестов
поднимаются на loopback со случайными портами и завершаются после проверки.
Пароль передаётся runner через stdin и не выводится. Зависимости browser QA
не добавлены в production package.json. Новые access-тесты запускаются явно;
существующий CI не объявляется проверяющим Caddy/браузер.

  После уточнения пользователя найдены [ML-отчёты в GitHub](github-review.md):
  0,8287 до округления и batch-замер, не независимый повтор или HTTP-нагрузка.
  Подготовленные материалы исправлены; выдуманных submission/p95/RPS нет.
- Конфигурация доступа пока не принята Толей и не применена к VPS. Прямой внешний
  обход по IPv4/IPv6, HTTPS публичного адреса и вход с устройства жюри не проверены.
- Чистая установка и контейнерная сборка этой версии не выполнены. Валидация
  Compose не равна запуску контейнеров. Полный update.sh на сервере не выполнялся.

- На момент этого прогона у карты оставалась подпись «без остановок и подписей»,
  хотя они отрисованы. Позднее текст исправлен при независимом ревью;
  оформление карты сохранено.
- Python 3.14 выдаёт предупреждения deprecation в FastAPI/Uvicorn; тесты проходят.
  CI использует другое закреплённое окружение и заново не запускался.
