# Инструкция жюри по проверке TramFlow

Актуализировано 26 сентября 2026 для работающего `ml-handoff-v1`.
Интерфейс показывает готовый прогноз успешных валидаций/посадок за
ноябрь–декабрь 2025. Это исторический модельный пакет, не прогноз на сегодня
и не измерение заполненности вагона. Проверенный пакет —
`calendar-holiday-priority-v1`, календарная модель без погоды;
№ 5 имеет явно обозначенный нулевой baseline.

## Адрес и версия

Веб-адрес: [tramflow.ru](https://tramflow.ru/).
Последняя серверная проверка описана в [протоколе 25 сентября](../../verification-deployment-2026-09-25.md):
код `88144ef`, реальный пакет и сверка API/UI/CSV. Это датированный результат;
перед выступлением ведущий проверяет доступность и версию. Обновление GitHub
само по себе не обновляет VPS. Эта подготовка не выполняет деплой.

Если сайт запрашивает Basic Auth, используйте отдельно выданные данные.
Пароля в исходниках и архиве нет. Наличие шаблона защиты не доказывает, что
она включена на публичном адресе. При предупреждении HTTPS не продолжайте
вход: сообщите ведущему адрес и время. Не отправляйте пароль в общий чат.

## Проверка за две минуты

1. Откройте страницу, дождитесь прогноза. В подробностях проверьте run и
   ограничения. Для проверенного пакета run начинается `handoff-4c8d04b9`;
   полный ID есть в [протоколе пакета](../../verification-priority-implementation.md).
   При другом run не переносите на него метрики этой версии.
2. Выберите маршрут № 1, «День», 1 ноября 2025. График и таблица показывают
   24 часа в МСК. Сравните несколько часов и итог. Дроби — ожидаемые значения
   модели; исходная точность сохраняется при экспорте.
3. Выгрузите CSV. Это тот же результат и фильтры, что на экране.
   Измените маршрут или дату: экспорт недоступен до получения нового результата.
   CSV диспетчера содержит служебные поля и **не является конкурсным submission**.
4. Переключите неделю, затем месяц — ноябрь и декабрь. Это суммы тех же часов,
   по 7, 30 и 31 дневной строке соответственно. Даты вне пакета недоступны.
5. Выберите № 5 и прочитайте пояснение baseline: ноль не доказывает отсутствие
   движения. Переместите и увеличьте карту, выделите линию. Карта независима
   от выбора прогноза; остановочный пассажиропоток по ней не вычисляется.

Техническая проверка готовности:
[handoff/ready](https://tramflow.ru/api/v2/handoff/ready).
`model_loaded=false` здесь нормально: backend читает проверенный CSV,
не запускает модель. Старый `/api/v1/health` проверяет только совместимый
синтетический контур и не подтверждает готовность реального пакета.

## Локальный резерв из комплекта исходников

Нужны Python 3.12, Docker Engine/Desktop и Compose. Получите совместимый ML ZIP
от команды отдельно по разрешённому каналу. В web-архиве нет весов, реальных
данных и готового прогноза; без пакета будут карта и сообщение о недоступности.
Из корня распакованного `tram-forecast/`:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m backend.handoff.install /absolute/path/calendar-holiday-priority-v1.zip \
  --output artifacts/demo-release
export TRAMFLOW_HANDOFF_HOST_DIR="$PWD/artifacts/demo-release"
docker compose -p tramflow-demo -f compose.yaml -f compose.handoff.yaml up --build -d --wait
.venv/bin/python -m backend.handoff.check --base-url http://127.0.0.1:5173 \
  --release "$TRAMFLOW_HANDOFF_HOST_DIR"
```

Откройте [localhost:5173](http://localhost:5173). Используйте свободные порты
8000/5173; не останавливайте чужие сервисы ради демо. Импорт требует новый каталог,
при повторном запуске уже установленного пакета шаг импорта пропускается.
Первая установка зависимостей и сборка требуют сети либо подготовленного кэша.
Перед сценой один раз запустите этот резерв и сохраните проверенные скриншоты.
Остановка только своего стека:

```sh
docker compose -p tramflow-demo -f compose.yaml -f compose.handoff.yaml down
```

## Ошибки и границы

| Симптом | Действие |
|---|---|
| 503 / пакет недоступен | Повторить запрос; локально проверить установленный release и переменную процесса/mount |
| 410 / run сменился | Обновить доступный прогноз и повторить выбор; старые числа не подменяются новым run |
| 409 при CSV | Повторить запрос прогноза, затем экспортировать новый результат |
| partial / no_data | Прочитать покрытие; отсутствующее значение не считается нулём или полным итогом |
| Backend недоступен | Повторить после восстановления; синтетика не подставляется автоматически |
| Нет карты | Обновить страницу; администратору проверить поставку `network.json` |
| Сайт недоступен | Перейти на заранее проверенный локальный резерв |

Отказ backend проверяется только на собственном локальном стеке. Публичный сервер
для демонстрации ошибок не останавливать. Сценарные коэффициенты, остановочный
прогноз, переключаемая компоновка и годовой экран пока отсутствуют; их не искать
в этой версии. Репетиция и независимая приёмка владельцами — отдельные шаги.
