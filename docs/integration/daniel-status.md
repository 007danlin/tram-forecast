## Приёмка и репетиция

Сначала G3: один подтверждённый маршрут/период и пять одинаковых значений batch/API/UI/CSV. Затем проверки [AT-01..AT-23](../team-specs/acceptance.md). Если что-то не поддерживается данными, записать ограничение и согласовать сокращение охвата; не ставить «пройдено» по картинке.

Четырёхминутный сценарий из [личного ТЗ](../team-specs/daniel-integration.md) готов как план: цель/период -> пик и детализация -> проверенные факторы -> сценарий/CSV -> качество/отказ -> запуск/ограничения. Репетиция ещё не проведена. Сейчас можно показать только проверку synthetic-связки, без заявления о качестве прогноза или эффективности распределения вагонов.

Ближайшая передача: Игорь/Георгий предоставляют паспорт; Толя/Артём рассматривают CR-03..08, которые можно обсуждать до завершения обучения. Командные сообщения не отправлены, подтверждения не подставлены автоматически.
