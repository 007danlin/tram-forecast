## Воспроизвести проверку связи

Запустить приложение по README (локальные процессы или Compose при работающем daemon), затем из корня:

```sh
.venv/bin/python -m scripts.check_integration --base-url http://127.0.0.1:5173
```

Для проверки отказа остановить запущенный для теста backend и повторить команду: ожидается ненулевой код. Восстановить backend и повторить: ожидается успех. Не останавливать чужие процессы. В CI та же проверка вызывается через `python3` после готовности Compose.
