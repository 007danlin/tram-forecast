заголовки обоих raw CSV и структура двух XLSX. Сырые события не пересчитывались.
README SHA: `6f4db96b0a2396ee197669a5a075c1c6447ab8fae88fe23061618db59f987015`.
Опись полей, листов и SHA справочников — `evidence/final-closure/stop-input-audit.json`.
Предыдущий полный [аудит target](../../ml/reports/data-audit.md) сохраняется.

У успешной валидации есть маршрут и время, но нет подтверждённого stop_id,
direction_id, trip_id или координат. `place_id` официально означает площадку/депо.
В XLSX есть остановки, порядок, направления и пример расписания; они не создают
проверенную связь конкретного события с остановкой. README ограничивает
пересечение справочника маршрутами 1/5/7/11/12. Периоды действия расписания,
`actual_date`, `route_date_start`/`start_date`, `service_id` и применимость к истории
2025 не разъяснены. Геометрия схемы 2026 не исправляет эти пробелы.

| Что необходимо для расчёта | Фактическое состояние |
|---|---|
| Зерно target | Успешная валидация → маршрут × календарный час; подтверждено |
| stop/segment/direction | Есть названия полей справочника; семантика события и историческая версия не подтверждены |
| Timezone | Raw timestamp без зоны; МСК — продуктовая интерпретация, не подтверждение организаторов |
| Event → stop join | Подтверждённого ключа или алгоритма нет; join не выполнялся |
| Доля неоднозначных/непривязанных | Не измерима без определённого join; отсутствие метода не выдаётся за измеренные 100% |
| Баланс и дубли после join | Не проверены: остановочный target не строился |

Запрос организаторам подготовлен, **не отправлен**:

> Для бонусной остановочной детализации предоставьте идентификатор остановки
> на успешной валидации либо телематику ТС с временем и подтверждённое правило
> сопоставления события с остановкой/рейсом. Нужны исторические версии
> остановок, участков и направлений с датами действия за январь–декабрь 2025,
> календарь расписаний и расшифровка полей дат/service_id. Просим подтвердить
> часовой пояс, ключи, правила для повторных заездов/смены направления,
> неоднозначных событий и покрытия маршрутов. Формат передачи можете указать
> в соответствии с вашим источником; мы не предполагаем отсутствующую схему.

После получения: согласовать дополнительный совместимый контракт с владельцами,
проверить однозначность и кардинальность join, отдельно сохранить непривязанные
события и равенство «привязанные + непривязанные = исходный target». Затем
провести временную оценку и сквозную приёмку API/карта/CSV. Посадки на остановках
участка не равны числу пассажиров внутри вагона на участке. До этого route-hour
B2 и DS сохраняются; остановочный критерий не считается закрытым.
