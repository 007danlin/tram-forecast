## A1 — Модель и воспроизводимость

TramFlow прогнозирует успешные посадки по маршруту и часу на 61 день
(01.11–31.12.2025) по истории 01.01–31.10.2025. Конкурсная модель B2:
calendar_interaction_ensemble, смесь 0,96 × (0,425 × F01-HGBT + 0,575 ×
interaction-HGBT), seed 20250925. Все 14 640 ключей sample сохранены, № 5 —
нулевой fallback без успешной истории обучения. После float-смеси применяется
однократное округление floor(x+0.5). Подтверждённый Даниэлем результат
champion.csv — 0,84260; скриншот успешной строки от 26.09 18:50 сохранён.

Два независимых inference из исходного сохранённого B2 без fit в чистой Python
3.12.14 venv дали точные float/DS побайтно. В комплекте G0, model/metadata/schema,
код train/inference, точные inference pins, README и SHA256. Исходный training
commit/dirty state и полный lock обучения не записаны; это ограничение раскрыто.
Материалы: g0-b2.zip, sources.zip, demo-handoff.zip, g0-reproduction.json,
release-manifest.json, evidence/score. Точные версии — в [приёмке B2](b2-acceptance.md).

## A2 — Внешние источники

В модели используется календарь F01: праздники, переносы и рабочая суббота 2025.
Все 365 дат независимо сверены с официальным перечнем ЦБ; HTML snapshot,
контрольная сумма, HTTP receipt и таблица проверки приложены. Исторический момент
получения календаря при обучении неизвестен. Отдельная B2 calendar-off абляция
не выполнена; эффект старого календарного эксперимента не приписывается B2.
Погодные варианты испытаны и отвергнуты по результатам сравнения. Пробки и события
не заявляются используемыми факторами. Ручные поправки UI — допущения диспетчера.
Материалы: ml/external-sources.json, model-card.md, отчёт weather-groups,
score-v3 и evidence/calendar. Календарные первичные ссылки указаны в реестре.

## A3 — Запуск, API и сервис

Поставка запускается Docker Compose из чистого каталога по README. ML-артефакт
и готовый float-прогноз импортируются штатным валидатором в отдельный каталог,
который монтируется read-only. Проверены ready, API/UI/CSV, № 5, неподдерживаемые
маршруты и сохранение run после restart. Основной API выдаёт неизменяемый batch;
ML inference и обучение на HTTP-запросе не выполняются. Поддерживаются
день/неделя/месяц, ручные сценарии, качественный год и сводка маршрутов.
Экспорт закреплён за run/result; устаревший результат получает 409.
Материалы: README.md комплекта, sources.zip, demo-handoff.zip,
[контракт](contract.md), [проверки](verification.md). Публичное размещение этой
версии выполняется отдельно; текущий локальный результат не выдаётся за VPS.

## A4 — Архитектура и применимость

Обучение/временная оценка → сохранённый артефакт → batch CSV → проверка ZIP и
manifest → read-only release → FastAPI snapshot → React UI и закреплённый CSV.
Версии модели, датасета, схемы и прогноза связаны в manifest. Пропуски остаются
null, неполное покрытие отображается явно. Карта связана с историческим target
по номеру маршрута: схема 2026 не доказывает историческую топологию 2025.
Сервис помогает выбрать маршрут и время для проверки выпуска и интервалов.
Он не оценивает заполненность вагона или число дополнительных вагонов.
Материалы: docs/architecture.md, INTEGRATION.md, contract.md, limitations.md.

## A5 — Производительность и реализованные дополнения

На B2 выполнен локальный сценарный smoke k6 → Vite → FastAPI: один worker,
2 CPU / 4 GiB, прогрев 50 RPS × 30с, затем 200 RPS × 60с. 12 001 сценарный
запрос, 199,945 RPS, p95 16,042мс, ошибок и dropped iterations 0, семантические
проверки 100%. Это выдача и агрегация batch, не ML inference или замер VPS.
Ресурсные показатели основаны на 19 срезах; их ограничения раскрыты.
Ручные коэффициенты меняют UI/API/CSV согласованно, не меняя базу. Качественный
год содержит три допущения без численной суммы. Обзор маршрутов сохраняет время,
отделяет baseline/partial и ведёт к панели маршрута с соседними интервалами.
Chromium/WebKit и мобильный режим проверены. Материалы: verification.md,
tests/load, evidence/load, browser evidence, резерв demo.webm.

## A6 — Ограничения и развитие

Посадки не равны уникальным пассажирам или заполненности. Нет подтверждённых
stop mapping, направлений, высадок, вместимости и расписания для оптимизации парка.
Десяти месяцев истории недостаточно для проверенной численной годовой сезонности.
Сценарные интервалы не оценены. S1–S4 пересекаются; D использован повторно,
поэтому независимый blind holdout не заявляется. Первоначальный training commit
и полный lock неизвестны. Следующие шаги требуют новых подтверждённых данных
и отдельной оценки эффекта; остановочная модель и две реплики не реализованы.
Репетиции и личная командная приёмка отложены по указанию Даниэля.
Материалы: limitations.md, паспорт модели и датированные протоколы.
