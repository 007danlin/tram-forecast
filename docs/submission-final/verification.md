импорт B2 — командами README через новый backend image. Нет зависимости запуска
от developer Downloads, локальной .venv, датасета или прежнего project image.
Первая сборка требует registry/npm/PyPI. Docker: Python 3.12.10, Node 22.16.0,
Engine 29.4.0. `/data/handoff` — RW=false. После `up --force-recreate --wait backend`
сохранены точный run и 14 640 строк. `backend.handoff.check` в контейнере сверил
первую/последнюю дату всех десяти маршрутов, часы, daily sums и CSV.

`tests/frontend/dispatcher.cjs` прошёл на B2 в Chromium и WebKit: D1/D2/D3,
API/UI/CSV, 422 коэффициенты, 409 stale export, быстрые правки, reset, месяц,
год без численного запроса, baseline и unsupported, общий выбранный час,
нет сети на tick, 390px без переполнения страницы (таблица имеет свой scroll).

Полный Chromium `tests/frontend/run_browser.py` на B2 проверил первый/последний
день всех маршрутов против source CSV, missing release/recovery, 503/410/409,
null/partial/no_data, МСК в браузере America/Los_Angeles, клавиатуру, адаптивность,
темы и карту: 35 вариантов, 45 фрагментов, подписи/значки/видимый фокус. Снимки
проверены визуально. Геометрия карты этой работой не менялась.

Полный комплект повторно собирается одной командой с `--supporting-bundle`,
исходным template из G0 и принятым подтверждением score. G0/evidence копируются
