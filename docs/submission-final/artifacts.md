## Форма: отдельный контроль

Разместить утверждённые материалы только по отдельной команде. Затем отдельной
сессией с правами жюри открыть каждое A1–A6, сверить bytes/hash, дату проверки
и запасной локальный комплект. Ограничения исходного training provenance в A1 раскрыть явно; локальная приёмка inference не заменяет доступ по ссылке.
Поля формы подготовлены содержательно этой таблицей; публичные URL пока отсутствуют.
После отдельной команды сохранить самостоятельный receipt формы. Успех DS не
доказывает сохранение формы и наоборот.
