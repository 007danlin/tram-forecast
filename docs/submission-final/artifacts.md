# Что указывать в шести полях формы

Версия подготовки: 27.09.2026, C01 для конкурса и B2 для веба. Полный архив и папка на Диске должны относиться к одной версии. Подготовленная папка сама по себе не означает, что жюри уже имеет доступ.

| Поле формы | Материал в полном комплекте | Что вставить после загрузки |
|---|---|---|
| 1. ML-модель, обучение/инференс и README | `competition/model-package.zip`, `guides/model-current.md`, `sources.zip` | Ссылку на общую папку комплекта или на папку с моделью и инструкцией |
| 2. Все внешние данные | `external-data/`, `guides/external-data.md`; исходные снимки также внутри модели | Ссылку на папку внешних данных вместе с описанием источников |
| 3. Веб-сервис, Docker, API | `sources.zip`, `demo-handoff.zip`, `guides/web-launch.md` | Ссылку на комплект; если поле допускает текст, дополнить проверенным адресом https://tramflow.ru/ |
| 4. Архитектура и применимость | `guides/architecture.md`, `guides/model-current.md`, `guides/limitations.md` | Ссылку на папку инструкций или общий комплект |
| 5. Производительность и дополнения | `guides/performance.md`, `evidence/web-b2/` | Текст из `FORM-FIELDS.txt`, при необходимости ссылку на доказательства |
| 6. Ограничения и развитие | `guides/limitations.md` | Текст из `FORM-FIELDS.txt` |

[Готовые тексты](submission-fields.md). Первые четыре поля на снимке требуют ссылок, два последних — текст. Лимиты длины не видны. Одинаковая ссылка на общую папку допустима как подготовленный вариант, если платформа принимает URL и жюри видит все названные файлы.

Отдельный DS-файл: `competition/submission.csv`, C01, SHA-256 `743b9cebf61c18c5ba829b21993aa7c8c58e2e1a3419efd40ab0a3fb96da6e12`. Переименование файла не меняет его байты. Результат 0,89003 записан по сообщению Даниэля; повторная отправка того же файла для подготовки формы не нужна.

Перед сохранением формы: проверить скачивание по каждой ссылке без аккаунта владельца, удалить подсказки-заглушки из полей, затем сохранить и убедиться, что платформа показывает последнюю версию. Успешный DS и сохранённая форма — два разных подтверждения.
