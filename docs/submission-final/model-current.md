Маршруты модели: 1, 7, 11, 12, 17, 25, 26, 28, 50. № 5 имеет нулевой результат для сохранения полного шаблона. ## Повторить прогноз

Из корня полного комплекта. Нужен Python **3.12**. Пакет был проверен в окружении с numpy 2.3.3, pandas 2.3.3, scikit-learn 1.7.2, joblib 1.5.2 и CatBoost 1.2.8. Полный lock сохранён внутри. Первая установка требует сети.

```sh
mkdir -p runtime
unzip competition/model-package.zip -d runtime/c01
python3.12 -m venv runtime/c01-venv
runtime/c01-venv/bin/python -m pip install -r runtime/c01/requirements.lock.txt
runtime/c01-venv/bin/python -m pip check
export PYTHONDONTWRITEBYTECODE=1
runtime/c01-venv/bin/python runtime/c01/code/reproduce.py \
  --root "$PWD/runtime/c01" --candidate C01 --output "$PWD/runtime/c01-replay"
shasum -a 256 runtime/c01-replay/submission-v11-c01-20260927.csv
```

Ожидаемый SHA-256:
`743b9cebf61c18c5ba829b21993aa7c8c58e2e1a3419efd40ab0a3fb96da6e12`.
Float SHA-256:
`319d86495cfa5a4e8454617eb8c6b5561dc821ad553d1211b5f499dde817e253`.

Каталог результата должен быть новым. Скрипт рассчитывает цепочку из сохранённых моделей без обучения. Эталонные ответы читаются для последующей проверки. Итоговый `verification.json` должен содержать только успешные проверки. Это автономный Python batch; B2 Dockerfile нельзя выдавать за контейнер C01.

## Где код обучения и проверки

После распаковки архива:

- `workers/G/COMMANDS.md`, `workers/G/code/` — обучение/оценка G и расчёт из модели.
- `workers/L/COMMANDS.md`, `workers/L/code/` — оценка/сохранение модели L и её расчёт.
- `parents/v10/` — родительские модели и их код; `code/reproduce.py` повторяет полную цепочку.
- `registration.json`, `metrics.csv`, `RESULT.md` — настройки и результаты временных проверок.
- `verification/clean-unpack-replay.json` — повтор после чистой распаковки.
- `manifest.json` — контрольные суммы всего исходного пакета.

Внутренние `HANDOFF.md` и `RESULT.md` зафиксированы до сообщения результата C01 и могут называть E01 прежним лидером. Они сохранены как история. Текущий статус вынесен в `competition/selection.json` и эту инструкцию. Исторические ограничения времени эксперимента не являются необходимым шагом inference.

Для нового обучения нужны отдельно полученные разрешённые данные и повторная оценка; работающий replay этого не требует. Часть команд исследовательского обучения привязана к историческим каталогам: пути нужно задать для новой копии. Локальные проверочные окна пересекаются и использовались повторно; их метрики не считаются независимым тестом.

Внешние факторы используются в конкурсном ретроспективном режиме: фактическая погода и поздние сведения о движении могут быть известны уже после даты прогноза. Такой результат не равен качеству ежедневного прогноза в эксплуатации. [Источники](external-data.md), [ограничения](limitations.md), [замена модели](update-model.md).
