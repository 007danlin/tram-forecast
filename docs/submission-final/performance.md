# Производительность и дополнительные возможности

Ниже — выполненные ранее замеры с сохранёнными протоколами. Новая упаковка не превращает их в новые тесты и не переносит результат B2 на C01.

| Проверка | Среда и длительность | Результат |
|---|---|---|
| HTTP, готовый базовый прогноз | Локальный Docker, Vite → FastAPI, 1 worker, 2 CPU / 4 GiB; 200 RPS × 5 минут | 199,967 RPS, p95 9,310 мс, 0 ошибок, 0 пропущенных итераций |
| HTTP, сценарий с двумя поправками | Локальный B2, 1 worker, 2 CPU / 4 GiB; прогрев 50 RPS × 30 с, 200 RPS × 60 с | 12 001 запрос, 199,945 RPS, p95 16,042 мс, 0 ошибок |
| Расчёт B2 из весов | Docker Linux ARM64, 2 CPU / 4 GiB, без swap; полный forecast 14 640 строк | 3,05–3,15 с; максимальный RSS четырёх полных вызовов 184,39 MiB |
| Расчёт B2 из весов на VPS | Docker Linux AMD64, 2 CPU / 4 GiB, без swap; полный forecast 14 640 строк | 10,75–11,26 с; максимальный RSS четырёх полных вызовов 186,80 MiB |

RPS — запросов в секунду; p95 — время, быстрее которого завершились 95% запросов. В первом HTTP-тесте наблюдались максимум CPU 45,68% от лимита двух CPU, RSS после прогона 64 788 KiB и VmSwap 0. Время Docker включает запуск контейнера. Это разные проверки: выдача готового прогноза и расчёт из модели.

Протокол HTTP: [verification-load](../verification-load.md). Протокол сценария: [verification](verification.md). Docker: [docker-inference-verification](docker-inference-verification.md). В полном комплекте исходные отчёты и логи находятся в `evidence/web-b2/`, документация — в `sources.zip`.

Ограничения: HTTP-замеры локальные, не VPS; сценарный тест проверял два коэффициента; новый тест четырёх коэффициентов не проводился. Значения batch — отдельные наблюдения, не p95. Для C01 этих измерений пока нет. Горизонтальное масштабирование несколькими репликами не проверено.

Реализованы: день/неделя/месяц, обзор маршрутов и карта, выбор времени, график и таблица, CSV с фиксированной версией результата, четыре ручные поправки с отдельным CSV, мониторинг внешних источников, качественные годовые сценарии и план по кварталам. Панель «Проверить выпуск» помогает сопоставить соседние интервалы и выбрать дальнейшую проверку диспетчера. Остановочного прогноза и автоматического расчёта числа вагонов нет.
