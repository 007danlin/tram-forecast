## Выполненная проверка

- Оба исходных labels-файла прочитаны независимо; проверены схема, диапазоны,
  уникальность ключа и границы периода.
- Для четырёх маршрутов восстановлены 29 184 ячейки: 304 даты, 24 часа;
  средние включают нулевые ячейки, пн–пт содержат 218 дат, сб–вс — 86.
- Все 106 численных значений в трёх CSV сверены с независимым пересчётом
  из labels с абсолютным допуском `1e-6`.
- Последний скрипт без изменений запущен в отдельном временном каталоге
  на Python 3.12.1. Встроенные проверки прошли; численные различия трёх
  воспроизведённых CSV с принятым комплектом равны нулю.
- Скрипт создаёт все три SVG из сохранённых CSV. Проверено соответствие
  линий значениям; экспортированные графики просмотрены визуально.
- Тексты защиты сверены с числами и ограничениями анализа.

Для повторения нужны Python 3.12+ и pandas/numpy/matplotlib; точные версии
проверенного окружения сохранены в локальном `verification.json`. Скрипт ищет
два labels-файла рядом с собой и пишет туда же результаты. Повторять в новом
каталоге, не перезаписывая `accepted/`; инструкция — в локальном README.
