# Контракт локальной реализации D1–D3

26.09.2026. Решение для совместной локальной реализации frontend/backend по поручению
Даниэля. Это не запись о полученном личном одобрении Толи, Артёма или Георгия.
Несовместимых изменений существующего handoff, ML batch и DS нет.


**Обновление продукта 26.09:** по новому поручению Даниэля ручные поправки
возвращены в UI для четырёх категорий мониторинга. При всех коэффициентах 1
используется базовый handoff; иначе — отдельный сценарный query/export.
Сборщики и `/api/v2/monitoring/status|records` сохраняют независимость от B2/DS.
Поправки задаёт пользователь; онлайн-снимки не становятся ML-признаками.

- `POST /api/v2/scenarios/query` принимает существующие filters и `coefficients`
  (`weather`, `event`, `closures`, `changes`, числа 0.5–1.5 с шагом 0.05).
  Значение = base × weather × event × closures × changes. Все значения по умолчанию 1.
  Новые поля необязательны; старые двухфакторные запросы сохраняют result_id.
  CSV добавляет новые колонки, когда эти поля переданы в экспортном запросе.
  Ответ `manual-scenario-v1`: неизменный `base`, отдельные rows с `base_value`,
  `value`, `delta`, total/delta_total, coefficients и собственный result_id.
- `POST /api/v2/scenarios/export` требует run и expected_result_id сценария.
  CSV содержит base/scenario/delta, коэффициенты, base_result_id, scenario result_id,
  статус/coverage и единицу. Никакого изменения DS. `null` и baseline сохраняются.
  Сценарные интервалы не оценены; базовые bounds остаются только внутри base.
- Capabilities получает совместимые дополнительные описания `scenario` и `year`.
  `scenario_supported=true` означает доступность отдельного ручного сервиса.
  Базовый query по-прежнему отвергает coefficients; его значения и ID не меняются.
- Год: статическое версионированное описание из `ml.cli.command_year_scenario`,
  `qualitative_available=true`, `numeric_supported=false`, `value=null`.
  UI показывает 12 месяцев с начала выбранного месяца, ограничения и три допущения.
  Численного запроса/экспорта за год нет; лимит base API остаётся 31 день.
- Обзор: один multi-route запрос существующего API (или отдельного сценарного
  сервиса при выбранном слое). № 5, partial/no_data отделены от полного модельного
  рейтинга. Тик времени не вызывает сеть. Выбор маршрута сохраняет дату/время.
- Карта: только динамическая маршрутная панель рядом со схемой. Геометрия и подписи
  не изменяются. Схема 2026 и прогноз 2025 не имеют доказанного stop mapping.

Статус приёмки и численные свидетельства публикуются в локальном verification.md
после проверок. Внешнее согласование владельцами и публикация остаются отдельными.

26.09 Даниэль явно отложил командную приёмку: локальная поставка продолжается
без личных подписей владельцев. Это не объявляет их согласование полученным.

## Локальное уточнение 27.09

HTTP/ML/DS-контракты сохранены. Год использует существующие `year`, route method и базовые строки текущего ответа; дополнительных метаданных и сетевых запросов нет. Проверенный исторический профиль маршрута не передан — показывается ограниченное состояние. Для baseline/unsupported/обзора персональные сценарии не отображаются. Квартальный план — условные действия, не сезонный расчёт. Окно сохраняет маршрут, дату, выбранную точку и коэффициенты. Блок проверки выпуска сравнивает текущую точку с соседями; при неполном периоде численная разница подавлена.
