# Комплект сдачи TramFlow

Это неизменный снимок комплекта C01/B2 от 27 сентября 2026 года. После его сборки в реестре появился новый лидер R03 / 0,89061; для него нужен новый проверенный комплект. Конкурсная модель — **C01 (0,89003 по сообщению Даниэля)**; запускаемый веб-комплект — **B2 (0,84260)**. Новую модель Георгия добавим после получения и проверки. Форма этим действием не отправлялась.

Пакет содержит веса и агрегированные производные организаторских данных. Исходный `dataset.zip`, пароли, `.env`, Git-история и виртуальные окружения в него не входят. Полный комплект предназначен для передачи жюри; исходники отдельно можно взять из `sources.zip`.

## Как проверить решение

1. Распаковать полный архив в новый каталог и проверить `shasum -a 256 -c SHA256SUMS` (Linux: `sha256sum -c SHA256SUMS`).
2. Открыть [инструкцию запуска веба](web-launch.md). Нужны Docker и Compose ≥2.24.4; всё остальное поставляется в комплекте.
3. Для повторения лучшего конкурсного CSV открыть [инструкцию C01](model-current.md). B2 воспроизводится отдельной [Docker-инструкцией](../../ml/inference/README.md).
4. Посмотреть [внешние данные](external-data.md), [производительность](performance.md) и [ограничения](limitations.md).

В корне распакованного комплекта эти инструкции находятся в `guides/`. Команды выполняются из каталога, указанного в каждой инструкции. Старые протоколы сохраняют свои даты и версии; приёмка B2 не означает установки C01 в приложение.

## Что загрузить на Яндекс Диск

Создать папку этой версии и загрузить **полный ZIP**, его соседний файл **`.zip.sha256`**, а также **`START-HERE.html` и `FORM-FIELDS.txt`** для быстрого просмотра. Можно вместо ZIP загрузить распакованную папку целиком. Не загружать весь рабочий каталог проекта.

После загрузки открыть ссылку в приватном окне и убедиться, что жюри может скачать ZIP и инструкции. В первых четырёх полях формы можно указать одну ссылку на папку и путь к нужному материалу; если поле принимает только URL, указать ссылку на файл/папку из [реестра A1–A6](artifacts.md). Локальные пути `artifacts/...` не работают у жюри.

Для A3 дополнительно предусмотрен адрес [tramflow.ru](https://tramflow.ru/), но перед сдачей нужно проверить доступ и версию. Локальный архив содержит текущие исходники; обновление сайта выполняется отдельно.

## Две независимые сдачи

По предоставленному PDF нужны CSV в разделе Data Science **и** заполненная форма «Загрузка решения». В DS учитывается лучший результат, в форме — последняя сохранённая версия. Указанный в PDF срок: **27 сентября, 23:59 МСК**. Это сведения из переданного задания, не новая проверка платформы.

## Когда придёт новая модель

[Короткий порядок замены](update-model.md): получить полный пакет, повторить расчёт, обновить версию/источники/поля формы, собрать новый архив. Старый комплект оставить резервом. Изменение конкурсного CSV само по себе не меняет веб-приложение.

История предыдущего B2-комплекта и его упаковщика сохранена в [техническом руководстве B2](b2-bundle-guide.md). Это справочник старой поставки, а не список файлов текущего общего архива.
