# Единый выбор маршрута и контраст станций — 26.09.2026

Реализовано по дополнительному запросу пользователя после редизайна и исправления
непрерывности линий. Верхний список «Маршрут» и клик по карте изменяют один номер.
Кнопка «Линии схемы» удалена. При выборе сохраняется контраст всей линии, её точек
остановок и названий; остальная схема имеет opacity 0.4. При смене номера камера
вписывает маршрут. При смене даты, темы и временной точки камера сохраняется.
«Вся схема» сохраняет выделение. Крестик/«Все маршруты» снимает его и очищает прогноз.

## Данные и интерфейс

`useNetwork` загружает геометрию один раз для карты и общего списка. Список объединяет
номера схемы и capabilities. Для доступных номеров сохраняется весь прежний
ready → capabilities → query → закреплённый CSV. Выбранный номер передаётся API точно,
без подстановки соседнего маршрута. Для номера вне capabilities нет query, KPI,
таблицы, временного ряда и скачивания старого CSV; показывается «Для этого маршрута
нет прогноза в подключённом пакете». Выбор во время загрузки capabilities не теряется.
При недоступном API карта работает; при сбое геометрии работают API-маршруты и CSV.

Это связь интерфейса по напечатанному номеру. Совпадение остановок/трассировки схемы
2026 года с историческим пакетом 2025 года не утверждается. Остановочного прогноза нет.
Общая геометрия 6/6к сохранена. При отдельном наличии 6к в capabilities его точный
номер сохраняется при клике на общий коридор. Backend, ML и `handoff.ts` не изменены.

## Векторные подписи

424 существующих label ID получили ссылки на 532 оригинальных контура из того же
PDF (`13bf11ade2d5a36bd3af8b4990e505e9692cf39eacbdb91f79e419f83bcf5c6f`).
`build_label_outlines.py` связывает их с исходными glyph paths, а `build_reference.py`
добавляет именованные группы `station-label-lNNN` в тот же локальный SVG. Runtime
использует `<use>`; исходный шрифт/начертание/координаты не воспроизводятся OCR-текстом.
`svgo-reference.mjs` сохраняет публичные fragment IDs. Prebuild проверяет ссылки и hash.

Восстановлены пять пропущенных OCR-группировкой строк по исходным контурам с общим
левым краем и межстрочным интервалом, включая первую строку «10-я улица» у l359.
Две строки «Клуб Русакова — Сцена „Мельников“» относятся к одному пучку; l318 больше
не подсвечивается с № 36. Подпись l358 «Семёновская» связана с соседним пучком;
три stop-записи, ошибочно ссылавшиеся на l318, теперь ссылаются на l358.
Это локальная проверка оформления по PDF, не полная новая инвентаризация остановок.
Геометрия 45 lanes, координаты 1093 stops и все прежние IDs сохранены.

## Проверка

- `npm run build`: TypeScript, проверка комплектности SVG, 35 групп / 36 номеров,
  связность всех 45 участков, свой набор остановок/подписей и отсутствие чужих линий.
- `map-continuity.cjs`: все 35 вариантов списка и 45 кликов по фрагментам в Chromium
  и WebKit; полный маршрут и соответствующий номер в верхнем списке; остановки,
  подписи и бледный фон. Сохранены семь крупных кадров стыков и петли № 50.
- `run_browser.py`: синтетический и реальный локальный `calendar-holiday-priority-v1`;
  batch → API → UI → CSV, день/неделя/месяц, baseline, МСК, 503/410/409,
  partial/no_data, устаревшие ответы, темы, жесты и адаптивность — пройдены.
- `route-focus.cjs`: Chromium и WebKit; CSV выбранного № 11, отмена/поздний ответ
  при переходе на № 36, отсутствие старых цифр/CSV, снятие выделения, медленный и
  недоступный API, сбой геометрии; обе темы на 390 и 1280 px — пройдены.
- `webkit-smoke.cjs`: мобильные поля, темы, таблица/CSV, fullscreen/фокус и текст
  200% на 390/1280 px — пройдены.

Идемпотентность подготовки подписей, `check_delivery.py` и три теста упаковщика
web-комплекта пройдены. Проверка diff не выявила пробельных ошибок.

Скриншоты остаются локально в `artifacts/verification/route-focus/`,
`map-continuity/`, `ui-synthetic/`, `ui-real/`. CI запускает синтетическую связку
и сохраняет снимки; перечисленные результаты — локальные запуски, не отчёт GitHub Actions.
Публичный сервер этой доработкой не обновлялся; реальные пакеты и PDF в Git не добавлены.
