# ML — Георгий и Даниэль

`forecast.py` — детерминированная заглушка для проверки подключения, без обучения и внешних зависимостей.
`adapter.py` — граница совместимости с backend v1: проверяет `forecast.CONTRACT_VERSION` перед вызовом неизменённого `predict_mock()`. Версия `synthetic-v1` относится только к текущему ответу. При несовместимой/отсутствующей версии выбрасывается `IncompatibleForecastContract`, провайдер не вызывается, backend возвращает прежний 503. Прямой вызов `predict_mock()` сохранён.
Интерфейс, ошибки и временная схема описаны в [INTEGRATION.md](../INTEGRATION.md#ml--георгий-интерфейс--даниэль).
После выдачи задания согласуйте замену с backend. Пока не создавайте признаки или формат входного датасета.

Будущий `predict(request, context)` и проверка реальных модели/feature schema/manifest не реализованы: [открытые решения CR-01/02/03](../docs/integration/contract-review.md). Формат определят после аудита Георгия и Игоря.
